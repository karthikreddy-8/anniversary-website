## 🛠️ Special Features & Technical Details
- **Session Progress Memory**: Progress is saved during the browser session so Anna & Vadina can click through or jump back to any unlocked stage using the top progress bar.
- **Background Music**: Controlled by a floating play/pause pill button (`Play Music 🎵`).
- **Zero Stock / Placeholder Images**: Only their 9 real uploaded photos are used throughout the entire application.
- **Aspect Ratio & Quality**: All images are preserved with `object-fit: cover / contain` with zero stretching or distortion.

## 🚀 Simple Commands to Run the Website

### Method 1: Instant Browser Launch (Fastest)
In PowerShell or Command Prompt, run:
```powershell
start index.html
```

### Method 2: Run with Local Server (Best for Audio & High-Res Images)
In PowerShell or Command Prompt, run:
```powershell
python serve.py
```
Then visit:
👉 **http://localhost:5173**
